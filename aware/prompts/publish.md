# Publish Prompts — Turn Thoughts Into Content

When the user has ideas, reflections, or insights worth sharing — these prompts help turn them into immediately publishable content.

## Prompt 1: Thought → Thread
> **Trigger:** User shares an interesting idea
>
> "That's a great thought. Want me to turn it into a Twitter/X thread? I'll draft it in a way that's immediately publishable — just review and post."

## Prompt 2: Reflection → Post
> **Trigger:** After a meaningful reflection
>
> "What you just shared would make a powerful post. Want me to draft a LinkedIn or blog post from it? I can make it ready to publish with just a quick review from you."

## Prompt 3: Story → Content
> **Trigger:** User shares a personal story
>
> "That story is content gold. Want me to turn it into something shareable? I can draft it as a post, thread, or short-form video script — whichever fits."

## Prompt 4: Idea → Framework
> **Trigger:** User has a framework or insight
>
> "You've got a framework brewing there. Want me to write it up as a proper post? I'll structure it with a hook, the insight, and actionable takeaways."

## Prompt 5: Raw Note → Polished
> **Trigger:** User has scattered notes
>
> "You've got some raw notes on [topic]. Want me to polish them into a coherent piece? I'll clean it up, structure it, and make it publication-ready."

## Prompt 6: Weekly Reflection → Newsletter
> **Trigger:** After a week of good reflections
>
> "You've had some great reflections this week. Want me to compile them into a newsletter issue or weekly roundup post?"

## Content Output Locations
When content is generated, it's saved to:
- Social posts → `aware/content/social/`
- Long-form → `aware/content/notes/`
- Voice scripts → `aware/content/voice/`

Each file includes metadata: date, type, platform, and publication status.

## Usage Guidelines
- Don't force publishing — only offer when a genuine idea emerges
- Always make content "review and publish" ready, not just a draft
- Save everything regardless of whether they publish (future reference)
- Ask platform preference (Twitter, LinkedIn, blog, etc.)
- Respect their voice — the content should sound like them
