# Process Prompts — Set Up Automations & Systems

When the user mentions something repetitive, frustrating, or aspirational that could be systemized — these prompts help turn it into an automated process.

## Prompt 1: Pain Point → Process
> **Trigger:** User mentions a recurring annoyance
>
> "You've mentioned [annoyance] comes up a lot. That sounds like something we could automate or systemize. Want to design a process for it?"

## Prompt 2: Aspiration → Habit
> **Trigger:** User mentions something they want to do regularly
>
> "You want to [aspiration]. That's a great candidate for a repeatable process. What would the ideal version of that look like? We can build a trigger + action system for it."

## Prompt 3: Review → Improve
> **Trigger:** After a reflection reveals friction
>
> "You mentioned [friction point]. Let's design a system that removes that friction. What's the manual step we can automate or the decision we can pre-make?"

## Prompt 4: Content → Pipeline
> **Trigger:** User has ideas they want to publish
>
> "You've had a few content ideas recently. Want to set up a content pipeline? We can create a process where you share a raw thought and I turn it into publishable posts."

## Prompt 5: Decision → Template
> **Trigger:** User makes similar decisions often
>
> "You make [type of decision] pretty regularly. Want to create a decision framework or checklist so you don't have to think about it from scratch every time?"

## Prompt 6: Energy → Schedule
> **Trigger:** When energy patterns become clear
>
> "I'm noticing your energy peaks around [time] and dips around [time]. Want to set up a schedule that aligns your hardest work with your peak energy?"

## Usage Guidelines
- Listen for process opportunities in natural conversation
- Offer process prompts when you spot a pattern, not randomly
- When they say yes, design the process together step by step
- Save processes in `aware/processes/` and integrate with automations
- Start small — the smallest useful process beats the perfect one
